## Audit Fase 8 (2026-10-19)

Metode: skill `owasp-audit` (daftar periksa OWASP 2021, dipetakan ke 2025), `route:list` lengkap (termasuk route Fortify, Boost, Inertia DevTools, dan storage), pemindaian otorisasi setiap aksi controller, sweep pola injeksi, XSS, SSRF, dan rahasia, payload XSS kanonik terhadap `HtmlSanitizer`, audit dependensi, lalu putaran kedua yang adversarial terhadap perbaikannya sendiri. Catatan deploy dari putaran kedua: dengan TrustHosts aktif, request ke `/up` dengan header `Host` berupa IP internal dibalas 400. Health check load balancer harus mengirim host publik, atau host/IP-nya didaftarkan di `TRUSTED_HOSTS`.

### Diperiksa dan bersih

- **A01**: setiap aksi controller admin diotorisasi (Policy langsung atau FormRequest yang memanggil Policy). Controller situs dan API hanya memuat data terbit dengan 404 yang seragam. Redirect hanya ke URL bertanda tangan dari storage. Boost hanya aktif di local atau saat debug; Inertia DevTools hanya di local atau lewat gate. CSRF tanpa pengecualian. Base URL Media Center hanya dari env, tidak bisa diubah lewat Pengaturan.
- **A02**: CSP berbasis nonce, `frame-ancestors 'none'`, `object-src 'none'`, header keamanan lain. CORS bawaan tanpa kredensial untuk API publik baca-saja.
- **A03**: `composer audit`, `npm audit`, dan `npm audit --omit=dev` bersih. Dependabot aktif, GitHub Actions di-pin ke SHA, `ignore-scripts=true`.
- **A04**: bcrypt cost 12; tanpa MD5, SHA1, atau `rand()` untuk keamanan; tanpa rahasia di repo (sweep prefix kunci penyedia); kredensial Docker wajib dari `.env`; seeder memakai password acak bila tidak diisi.
- **A05**: semua query mentah memakai binding; tanpa `{!! !!}` di Blade; `v-html` hanya untuk HTML tersanitasi server (isi artikel, blok Teks) dan QR 2FA dari Fortify; data halaman Inertia dienkode dengan `JSON_HEX_TAG`; tanpa `unserialize`, `eval`, atau eksekusi shell; payload XSS kanonik dinetralkan; unggahan gambar dan PDF divalidasi dan diproses ulang.
- **A07**: rate limit login, 2FA, dan passkey; 2FA wajib untuk Super Admin dan Approver; atribut sensitif `User` disembunyikan dari JSON.
- **A08**: `content_blocks` divalidasi terhadap `BlockRegistry`; lockfile; tanpa skrip dari CDN.
- **A09**: setiap blok `catch` melaporkan atau mencatat galatnya; jejak audit dari Fase 5.
- **A10**: degradasi aman Media Center dan `BlockHydrator`; stack trace tidak tampil saat `APP_DEBUG=false` (diperiksa `security:check`).
